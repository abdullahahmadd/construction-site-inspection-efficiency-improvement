# Overview

This project focuses on improving the efficiency of the construction site QA/QC inspection process using the Six Sigma DMAIC methodology in a Saudi construction environment.

The project analyzes operational inefficiencies affecting inspection approvals, process delays, rework activities, and documentation management within construction QA/QC operations. The objective is to identify process bottlenecks, analyze root causes, and propose improvement opportunities to enhance inspection workflow efficiency and operational performance.

---

# Business Problem

The construction site inspection process was experiencing several operational inefficiencies, including:

- Delayed inspection approvals
- High inspection rejection rates
- Repeated rework activities
- Incomplete inspection documentation
- Communication gaps between site and QA/QC teams
- Slow approval response times

These issues resulted in:
- Construction delays
- Increased labor costs
- Reduced operational efficiency
- Resource utilization inefficiencies
- Reduced project productivity

# Project Workflow

## 1. Problem Identification
The project started with identifying operational inefficiencies affecting construction site inspection performance and QA/QC workflow efficiency.

## 2. Define Phase
A Project Charter and Team Charter were developed to define:
- project objectives,
- business impact,
- stakeholders,
- process boundaries,
- and improvement goals.

A SIPOC diagram was also created to define:
- Suppliers,
- Inputs,
- Process,
- Outputs,
- Customers.

## 3. Measure Phase
A Data Collection Plan was developed to identify:
- operational KPIs,
- inspection performance measures,
- process data requirements,
- and data collection responsibilities.

## 4. Process Mapping
A detailed construction QA/QC inspection process map and workflow diagram were created to analyze:
- inspection request flow,
- approval activities,
- scheduling,
- documentation handling,
- and rework processes.

## 5. Analyze Phase
Root cause analysis was performed using a Fishbone Diagram to identify key operational issues contributing to:
- inspection delays,
- communication gaps,
- documentation errors,
- and repeated rework.

Hypotheses were also developed to evaluate whether process improvements would significantly improve operational performance.

## 6. Improvement Opportunity Identification
Potential improvement opportunities were identified to improve:
- workflow efficiency,
- inspection scheduling,
- documentation standardization,
- and communication between operational teams.

# Key Findings & Business Recommendations

## Key Findings
- Manual workflow activities increased inspection delays
- Incomplete documentation caused approval bottlenecks
- Communication gaps affected scheduling efficiency
- Repeated inspection failures increased rework frequency
- Lack of process standardization reduced operational efficiency

## Business Recommendations
- Implement digital inspection tracking system
- Standardize inspection request documentation
- Improve scheduling coordination between departments
- Develop QA/QC checklist templates
- Enhance communication between site and QA/QC teams
- Reduce approval bottlenecks through workflow optimization
